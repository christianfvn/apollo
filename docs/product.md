# Product brief

## Established facts

- The project will be a web app.
- Development uses a coordinator with PM, UX Designer, Backend Developer, Frontend Developer, and QA roles.
- The workspace is named Apollo; a public product name has not been chosen.

## Open product questions

- Who are the primary users, and what problem should the app solve?
- What is the core user journey and smallest useful first release?
- How will we judge whether the first release is successful?
- What data, integrations, account access, and device support are needed?
- Are there delivery, budget, hosting, or technology constraints?

These are discovery topics, not a requirement to answer everything before any progress. PM should prioritize questions that affect the next feature. No features or technology stack have been selected.
